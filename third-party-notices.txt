# React Bits design references

The contained spotlight and edge-glow treatment adapts ideas and implementation patterns from React Bits by David Haz. The capability layout and character-reveal treatment reference Magic Bento and Decrypted Text; content, architecture diagrams and project interactions are authored for Jason's portfolio.

## Motion and layout references (2026-09-16)

- React Bits ScrollReveal: https://github.com/DavidHDev/react-bits/blob/main/src/ts-default/TextAnimations/ScrollReveal/ScrollReveal.tsx
  Adapted its scroll-linked rotation, opacity, blur and stagger pattern to the existing GSAP lifecycle and Chinese phrase segmentation. Covered by the React Bits notice above.
- SceneAI Brightly Hero: https://sceneai.art/landing-pages?asset=6a9695bc029ceb04cf14c822
  Visual reference for a full-frame cinematic background and open foreground composition. No SceneAI paid assets or prompts used.
- Aura Pixtora: https://www.aura.build/templates/pixtoracreativeagency
  Visual reference for editorial type hierarchy and separation of hero, capabilities and work. No template code or media copied.
